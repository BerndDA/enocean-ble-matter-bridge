# EnOcean–Matter bridge PCB

One board for the EnOcean gateway: a bare nRF52840, a TCM 515 and USB-C, pin-compatible with the Pro Micro build.

KiCad project, fabrication files (`fab/`), 3D-printed case (`case/`) and the generator scripts (`tools/`). Design, decisions, ordering and bring-up are on the wiki page [EnOcean Bridge PCB](https://github.com/BerndDA/enocean-ble-matter-bridge/wiki/EnOcean-Bridge-PCB).
