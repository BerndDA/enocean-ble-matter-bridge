# EnOcean carrier board (EnMT)

A Pro Micro nRF52840 (nice!nano) on a 2-layer carrier with a TCM 515, hand-soldered.

KiCad project, fabrication files (`fab/`), 3D-printed case (`case/`) and the generator scripts (`tools/`). Design, decisions, ordering and bring-up are on the wiki page [EnMT Carrier Board](https://github.com/BerndDA/enocean-ble-matter-bridge/wiki/EnMT-Carrier-Board).
